# Hi, I'm Fabio
I build and explore practical tools for education, workflow automation, and human-reviewed command interfaces.

My work combines JavaScript, Python, and a personal knowledge system called **FabioOS**. I am turning experiments into focused projects with clear setup instructions, tests, and documented limitations.

## Current work
- **MEGATRON Wrist Core** — a command-interface prototype with a visual session state machine and an in-memory demo queue. Standalone repository in preparation.
- **[Facility demos](https://github.com/fabiorabeloj/facility-demos)** — HTML interface experiments for educational and operational workflows.
- **FabioOS** — my personal knowledge and automation workspace. Its private context is kept separate from public demonstrations.

## What I value
Small reproducible examples, explicit boundaries, readable code, and improvements supported by tests.
