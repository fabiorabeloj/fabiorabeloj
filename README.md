## O que eu faço

- **Automação de processos**: fluxos no n8n, webhooks e integrações por API que tiram tarefas repetitivas da rotina.
- **Sites e landing pages**: páginas responsivas em HTML, CSS e JavaScript, pensadas para o celular e para gerar contato.
- **IA local e assistentes**: modelos rodando no próprio computador (Ollama), busca em documentos com fonte citada e agentes que pedem aprovação antes de agir.
- **Ferramentas para educação**: organização de acervo didático, materiais de revisão e rotinas de preparo de aula.
